HARDWARE LEARNING LAB — START HERE

1. Open the Git repository root in Visual Studio Code.
2. Read AGENTS.md and README.md.
3. Copy .env.example to .env.local and add real values locally only.
4. In the VS Code terminal run:
      npm ci
      npm run dev
5. Open http://localhost:3000 in your browser.

There is no demo account and no public self-registration. Public pages work
without login; protected dashboards, course lessons and portals require an
account provisioned by an administrator.

For database work, read supabase/README.md. The live project already has its
migrations. Do not run old scaffold SQL from an earlier archive.

Before committing any change, run:
      npm test
      npm run check
